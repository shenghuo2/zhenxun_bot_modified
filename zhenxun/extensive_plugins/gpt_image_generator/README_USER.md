# GPT改图 使用说明

## 命令

`#gpt改图` / `#GPT改图` / `大gpt` / `大GPT`

## 基本用法

```
大gpt 把图一的猫换成图二的狗
```

- 直接发送文字 → 文生图
- **回复**一条带图的消息 + 发指令 → 被回复消息的图片在前, 当前消息的图片在后, 按序作为参考图
- 只有图没有文字也行

## 参数

所有参数均可省略, 位置不限, 但 **必须在提示词前面**。

### 尺寸 `--size=` 或简写 `1k` `2k`

```
大gpt 2k a cute cat
大gpt --size=2k a cute cat
```

默认 `1k`。`1k`≈1024×1024, `2k`≈2048×2048。

### 比例 `--ratio=` 或简写 `16:9` `3:4` 等

```
大gpt 16:9 a landscape painting
大gpt 2k 16:9 a landscape painting
```

可用值: `1:1` `1:2` `1:3` `2:1` `3:1` `2:3` `3:2` `3:4` `4:3` `16:9` `9:16`

不指定时:
- 有参考图 → 自动匹配第一张图的比例
- 无图 → 默认 `1:1`

### 张数 `--count=` 或简写数字 `2` `3`

```
大gpt 2 a cute cat
大gpt --count=3 a cute cat
```

默认 1 张, 单次最多 3 张。每张消耗 1 次每日额度。

### 质量 `--quality=` 或简写 `low` `medium` `high` `max`

```
大gpt high a masterpiece
大gpt --quality=max a masterpiece
```

默认 `medium`, 越高质量越好但越慢越贵。

### 指定供应商 `--provider=` 或 `-p=`

```
大gpt -p=nowcoding a cat
大gpt --provider=clawnode a cat
```

大小写不敏感。指定后只用这一个供应商, 不用重试链。

## 限制

- 每日免费次数有上限, 按所在群计算 (每个群独立)
- 生成中不能并发提交
- 每次生成完成后有几十秒冷却期
- 生成中撤回命令消息 → 自动取消
- 一次最多生成 3 张

## 输出说明

回复消息包含:
- 生成的图片
- 分辨率、比例、质量、张数
- 耗时、token 消耗、费用
- 今日剩余次数、累计用量
